# SBTI-打工人无厘头生存测试

> 20道灵魂拷问，测测你是哪种赛博牛马。

## 简介

一款轻松有趣的人格测试 App，通过 20 道打工人日常场景题，生成你的专属"牛马人格"诊断报告。支持中英双语。

## 功能

- 🎮 25 道趣味测试题
- 🧬 16 种独家人格类型
- 📊 雷达图能力评估
- 🖼️ 生成确诊海报，一键分享
- 🌐 中英双语支持
